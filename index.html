MemWallet is a deterministic cryptocurrency address generator, like WrapWallet, but it works for Ethereum, Litecoin, Monero and Bitcoin. You never have to save or store your private key anywhere. Just pick a really good passphrase — many random words, for example — and never use it for anything else.

Given the same passphrase and salt, MemWallet will always generate the same address and private key, so you only need to remember your password to access your funds.

For more information on why this is safer than a regular brainwallet, see WrapWallet's help. MemWallet is a re-implementation of WarpWallet for other currencies. WarpWallet and MemWallet use the same algorithm, so they generate the same Bitcoin address for a given passphrase and salt.

The Algorithm

b = 1 for Bitcoin, 2 for Litecoin, 3 for Ethereum, 4 for Monero
seed1 = scrypt(key=(passphrase||b), salt=(salt||b), N=218, r=8, p=1, dkLen=32)
seed2 = pbkdf2(key=(passphrase||(b+1)), salt=(salt||(b+1)), c=216, dkLen=32, prf=SHA256)
wallet = generate_wallet(seed=(seed1 ⊕ seed2))
